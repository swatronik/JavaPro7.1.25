Apache Kafka + Docker + Java
Цель

Развернуть Apache Kafka в Docker с помощью docker-compose, создать тестовый топик, протестировать работу через CLI и написать два Java-приложения: Producer (отправляет сообщения) и Consumer (читает сообщения).

Задание

Поднять окружение Kafka в Docker с помощью docker-compose.
Проверить, что все контейнеры работают.
Создать топик test-topic через команду в терминале.
Отправить тестовые сообщения в топик через Kafka CLI.
Прочитать сообщения из топика через Kafka CLI.
Написать Java Producer, который отправляет случайные данные (например, фрукты) в Kafka.
Написать Java Consumer, который читает эти данные.
Проверить отправку и получение через Kafka UI.
Остановить контейнеры и удалить все данные.
